<h2>Create Super User</h2>

- Go To Terminal and Type : `python manage.py createsuperuser`
- Then Enter UserName and Password ( Email Skip by Pressing Enter Button ) </br></br>

<img width="1920" height="1080" alt="Screenshot 2025-11-25 232501" src="https://github.com/user-attachments/assets/48f0750b-c6b9-4694-9e9e-81d397452d94" /></br></br>

- Then Run : `python manage.py runserver`
- Enter Admin in the URL : `http://127.0.0.1:8000/admin` </br></br>
